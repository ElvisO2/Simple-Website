# Simple-Website
This is my personal portfolio site, built for Hack Club's Stardance program. It includes an About Me section and a Projects section, styled with a dark theme using HTML and CSS, with Space Grotesk as the main font. I built this to practice core web fundamentals like flexbox layouts, styling, and structuring a page with sections. I used Claude, an AI assistant, to help me relearn HTML and CSS concepts and guide me step by step while building this site, including troubleshooting issues along the way. The structure, content, and personal choices for the site are mine.
